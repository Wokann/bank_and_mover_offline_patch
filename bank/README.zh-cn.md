# Pokemon Bank 补丁

[English](README.md) · [项目首页](../README.zh-cn.md) · [原版流程与实现分析](docs/code-analysis.zh-cn.md)

支持本体 Title ID `00040000000C9B00`。功能通过同一套 `code.bps + exheader.bin + romfs/`
安装；不修改软件的原始段地址和 BSS 变量地址。

## 模式

| 标题模式 | 用途 | 银行／设置来源 |
| --- | --- | --- |
| 离线 | 管理本地银行、原版里程及可选本地礼物 | SD `bankdata.bin`、`sav.bin` |
| 下载 | 把官方银行完整导出至 SD，然后返回标题 | 官方银行与原存档；下载覆盖前应备份本地银行 |
| 解锁 | 原版联网事务恢复，显示返回的解锁候选 | 官方服务器与原存档，不上传离线银行 |
| 原版 | 完整官方菜单与联网银行流程 | 官方服务器与原存档 |

标题按 **R** 切换，按 A／START／触摸确认后锁定本次会话模式。返回标题保留当前选择，
重启恢复默认离线。离线修改没有上传官方服务器的功能。

标题按 **L** 可选择语言，提示沿用 Mover 的原文措辞、位于 HOME 提示上方；L、R 均使用专用按键字形。
语言仅可在标题选择。当前模式居中显示于 START 上方；下方依次是 R 模式切换、L 语言及 HOME 提示。
文本使用原白色、字号与整数像素坐标，不遮挡 START 或版权标记。
所有模式统一沿用主机原存档的语言。原存档未初始化时，先走原版语言选择并初始化，
再进入标题。重选语言先沿原流程保存主机记录，再同步 SD，完成后返回标题。
启动及语言保存完成时，`sav.bin` 缺失则完整复制有效原记录；已存在则仅在语言不同
时更新 `0x28–0x2B`，保留身份、事务和未知尾部。损坏或读取失败不按缺失覆盖；
SD 同步失败不会倒改主机记录，下次启动再尝试同步；SD 语言不用于加载界面语言。

前三种模式的不可用菜单保留原条目名并追加本地化禁用后缀，例如“转移至 Pokémon HOME（已禁用）”。
十套文本均限制在原窗格的 54 个 UTF-16 字符内，超宽时沿用原版横向缩放；原版模式的文本和功能不变。
支持代码在全部模式开放，沿原路径读取主机身份并生成显示，不使用伪造编号或本地事务令牌。
原系统调用失败、响应不完整或身份值为零等占位数据时，选单仅追加“（无效）”，仍可查看原结果；
有效响应保留原文。不额外联网或重读身份，不将显示代码当作官方账号认证成功。

离线及下载模式的标题左上角显示深灰色用户块：当前选择 `auto(实际编号)`／固定编号，
下一行显示 `编号=用户ID`。单用户无切换提示；多用户可用十字键／左摇杆的↑/↓选择，C 摇杆不参与。
按住可连续切换并加速；列表从 auto 到最大编号，两端不循环。浏览只操作内存，松手后合并后台保存；
进入前核对并提交最终 activeUser，再加载对应用户数据。
离线选择所使用的本地银行，下载选择本地写入目标；不会切换主机的官方联网账号。
解锁、原版模式隐藏此块，也不为进入官方流程核对无关的本地账户；离开本地模式时仍先完成已有选择的保存。
自动命名使用 ACT 账号用户名或 CFG 主机用户名，而非 PID；见[客户端说明](../configTemplate/templateForCopy/Bank/client/readme_client.zh-cn.md)。
主机／模拟器返回零身份时也不补造真实身份，显示结果不代表已连接官方账户。

免费活动独立于票务作业读取当前日期和地区配置，不能要求先完成票务查询。
活动正文交原回调校验，原使用权状态优先采用有效免费活动的菜单提示；已购券记录独立保留。

下载无需选择游戏；无可用游戏时可确认直接下载。官方账户未建行时先走原版创建。
本地没有银行时，离线模式可走原版首次创建；损坏数据或无法判定的未决工作不会当作
空银行覆盖。语言、游戏校验、盒子编辑、里程计算与原生存档保存仍由原客户端处理。

离线事务不匹配时，原“和上次不同的游戏软件”及训练家姓名／编号提示保持不变，确认后
用原版翻页机制追加一页三行说明：强制解锁可能丢失上次传输的宝可梦；先确认全部存档
均无法匹配本地服务器，再在选定游戏并确认时按住 L＋A＋START。解锁模式的选游戏提示
同样包含风险，但明确指官方服务器。此说明不修改匹配条件、强制解锁入口或原版收尾。

普通里程使用票务响应中的当前时间。真实联网使用服务器返回值，离线伪服务器用
主机时间生成该响应，因此改主机时间会影响离线计算，不会改变真实服务器时钟。

## 跨语言字形

三份主字库均覆盖默认银行／群组／盒子名称、十套第 1～807 号宝可梦名称及原输入表字符。
只复用／复制原生字形，不缩放文字、不修改存档；保留原字形编号与字宽，纹理占用不增加。
不保证任意汉化文本的全量 CJK；[覆盖、内存与校验说明](../common/docs/fonts.zh-cn.md)。

## 安装

按[项目安装说明](../README.zh-cn.md#安装)复制完整 Title ID 目录至 Luma。
Azahar 使用用户目录的 `load/mods/00040000000C9B00/`，不是虚拟 SD 中的
`sdmc/luma/titles/`。三部分必须成套更新，并移除同目录旧 `code.ips/code.bin`。
压缩补丁目录不放 README、更新日志、配置或存档。

## 本地事务日志

| 文件 | 作用 |
| --- | --- |
| `fakeServers/users/<用户ID>/bankdata.bin` | 当前完整银行正文 |
| `bankdata.bak` | 实际修改前的上一版银行，不在成功收尾时覆盖成新版 |
| `bankdata.tmp` | 正在准备／发布的正文，不是独立恢复权威 |
| `client/users/<用户ID>/sav.bin/.bak/.tmp` | 本地 Bank 设置及原事务记录 |
| `fakeServers/users/<用户ID>/transaction.bin/.bak/.tmp` | 个人跨文件协调日志及其上一发布步骤／暂存，不是银行正文备份 |

保存先暂存银行，经原游戏保存与回调决定提交／回滚，再清令牌并确认清理。
只读进入或不保存退出不轮替银行备份；Gen5 文件策略见 [Mover](../mover/README.zh-cn.md#保存与恢复)。
文件摘要使用 CRC32，随机编号／令牌仍来自随机源；CRC32 不是密码学身份认证。

不要凭文件名或时间戳猜测中断状态。保留无法判断的工作文件，按
[恢复组合与风险](../common/docs/fakeServer/architecture.zh-cn.md#删除损坏和手动换入的处理边界)
处理。合法主文件、备份、孤立暂存的接纳规则不同；旧 SHA-256 日志不会自动清除。
现有文件无法确定一致版本时，自动恢复会停止；请完整保留该用户目录及来源游戏存档，
不要以不匹配的备份强行替换。

离线事务挑战由伪服务器提供三个本地候选，沿原键盘和回滚流程处理；
它与“解锁模式”的官方联网恢复不是同一后端，也不是官方密码算法。
银行和设置可能含私人标识、训练家信息及时间记录，请勿公开上传。

## 注入空间来源与边界

新增代码和工作区位于原 BSS 后的独立页，包含 1 MiB I/O 缓冲、独立任务正文和后台栈。
原 SDK 仍拥有其对象／正文分配，后台不持有游戏对象的借用指针；界面只消费完整结果。
活动服务与配置分配会及时释放，不以全局常驻词表挤占原堆。

布局、钩子、加载器权限、主机能力判断及保留的原指令，详见
[代码分析](docs/code-analysis.zh-cn.md)。不支持的实机权限修改会报错，不绕过为假成功。

## 独立编译

需要 GNU Make、POSIX shell、Python 3 与 devkitARM，并设置 `DEVKITARM`。
仓库带 Windows armips／Floating IPS，其他平台通过 `ARMIPS`、`IPS_TOOL` 指定工具。

从自己拥有的同一本体提取解密、解压后的代码、完整 RomFS 与 ExHeader：

```text
bank/rom/
├── exheader.bin
├── exefs/00040000000C9B00.dec.code
└── romfs/
```

代码为 `2,801,664` 字节，SHA-1 为 `5AB630856835DCF2DBDF9A62244DD19E46AE1C7C`。
推荐使用 GodMode9 挂载根目录的完整 `0x800` 字节 `extheader.bin`，改名为 `exheader.bin`；
工具也识别 `0x400` 字节头部，但不得混用其他软件或更新标题的输入。不要提交或传播原资源。

```sh
make -C bank
# 如工具路径不同：
make -C bank ARMIPS=/path/to/armips IPS_TOOL=/path/to/flips
```

默认显示根目录 `VERSION` 加 Git 提交简写；正式构建须显式使用 `PATCH_RELEASE=1`。补丁版本显示在上屏左上角，官方版本号保持原样和原位置。版本更新及无 Git 源码副本的参数见[统一构建说明](../README.zh-cn.md#从源码构建)。

输出 `release/00040000000C9B00/`。构建自动执行 BPS 还原、原址／模式分派、ExHeader
和十种语言的静态检查。通常无需先运行 `clean`；它会删除本项目 `build` 和发行输出，
不要将存档或唯一数据保存在生成目录中。

## 使用限制

首次使用应先备份银行与游戏存档；不保证所有来源、礼物组合或真实断电场景。
技术边界见[共用服务说明](../common/README.zh-cn.md)。

真实联网仅在明确识别到模拟器缺失票务接口且全局策略允许时使用独立只读免费兼容响应；
不采用离线购买记录、商店余额或礼物配置，其他联网请求仍走原版。此兼容不保证官方服务接受
模拟器请求。原版支持码、HOME 和官方接口行为不得由本地服务伪报成功。

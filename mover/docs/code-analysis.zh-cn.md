# Poke Mover 代码分析

本文只记录对受支持原版二进制得到的静态分析结论，不描述补丁设计或构建步骤。当前维护
补丁的实现、事务规则和独立编译方式见 [`../src/README.zh-cn.md`](../src/README.zh-cn.md)。

## 目标与内存分布

- Title ID：`00040000000C9C00`
- 版本：v5.5.0
- 代码基址：`0x00100000`
- 解压代码 SHA-256：`001C20ADA74016507C969BB44A0A50F8EDF803EC06A3FC46834263BA8DF0FD2F`

| 区域 | 虚拟地址 | 属性 |
|---|---|---|
| `.text` | `0x00100000–0x0028E000` | 可读、可执行；实际内容结束于 `0x0028D1AC` |
| `.rodata` | `0x0028E000–0x002EC000` | 只读、不可执行 |
| `.data` | `0x002EC000–0x0032A000` | 可读写 |
| `.bss` | `0x0032A000` 起，长度 `0x3A4A8` | 可读写、零初始化 |
| 线程栈 | 长度 `0x40000` | ExHeader 配置 |

`.text` 的最后一个非零镜像字节位于 `0x0028D1AC` 之前；按 ARM 指令对齐后，可用尾部为
`0x0028D1B0–0x0028E000`，共 `0xE50` 字节。Ghidra 记录的最后指令/数据引用位置为
`0x0028D188`，最后函数结束于 `0x0028D18F`。当前离线载荷结束于 `0x0028DBF1`。
`0x0028DD00–0x0028DDE0` 的 `0xE0` 字节作为独立区域保留给 Transporter
Redirect Patch，`0x0028DFC0–0x0028E000` 保留给本项目的版本标识。本项目以后可使用
`0x0028D1B0–0x0028DD00` 和 `0x0028DDE0–0x0028DFC0` 两段空间；当前合计还剩
`0x2EF` 字节。

`.rodata`（`0x002EBA58–0x002EC000`，`0x5A8` 字节）和 `.data`
（`0x003293FC–0x0032A000`，`0xC04` 字节）的连续零值尾部不可执行，而且仍可能存在引用。
仅增大 ExHeader 的 `.text` 大小会与现有 `.rodata` 映射重叠。因此若要越过 `0x0028E000`
扩容，必须生成经过重定位的完整代码镜像并同步修改 ExHeader 段地址，不能只依靠 Luma
`code.ips`。

## 主流程与函数地址

| 地址 | 功能 |
|---:|---|
| `0x0019CEE4` | 19 项主状态对象工厂 |
| `0x00242BA0` | 根据流程结果选择下一主状态 |
| `0x00248C68` | 检查 Transfer Box 与传送许可状态 |
| `0x0025C978` | 下载并消费完整 Bank 文件 |
| `0x0024A0C4` | 传送、序列化、保存和提交状态 |

```text
选择游戏
  → 联网和传送许可检查
  → 从卡带读取、筛选并转换候选宝可梦
  → 下载完整 Bank 文件
  → 合并候选到 Transfer Box
  → 序列化完整 Bank 文件
  → 远端暂存
  → 卡带保存
  → 提交或回滚
```

## 网络状态

完整文件经 `0x0025C978 MoverDownload_ConsumeBankData` 载入。该函数先备份 30 个候选传送槽；下载文件的 Transfer Box 为空时，再恢复候选数据。

`0x00248D3C` 所在 state 1 在请求函数返回后会把状态写为 2；异步下载回调会直接把父状态推进到 3 或 7。

网络传输函数：

| 地址 | 功能 |
|---:|---|
| `0x0018AA38` | HTTP 请求准备与启动 |
| `0x0018B58C` | HTTP 流式发送和接收线程 |
| `0x0020815C` | 构造含 `name="file"` 的 multipart 文件流 |
| `0x00208554` | 输出 multipart 前缀、文件体和后缀 |
| `0x00215208` | HTTPC 分块发送 |
| `0x00215308` | 通知 POST 正文结束 |
| `0x00215328` | 接收响应 |
| `0x0025AF1C` | 准备 BankObject GET |
| `0x0025B02C` | 检查响应 `Content-Length` |
| `0x001F8D5C` | 初始化 HPP POST 作业 |
| `0x001F8EB8` | 处理 HPP 结果、重定向和重试 |
| `0x001F9194` | 重建重试请求 |

HPP 中的四段资源是 `CACERT_PUBLIC_CA_5.der` 至 `_8.der`，不是 bankdata。底层 HTTPC 返回成功不能替代上层 HTTP 状态、响应体、控制面完成结果和异步状态。

## BankObject 与 bankdata

Mover Bank 对象虚表：`0x002E6DD0`。文件内容对应对象 `+8`，固定长度 `0xBB518`。

| 虚表偏移 | 地址 | 功能 |
|---:|---:|---|
| `+0x08` | `0x0025AE44` | 序列化完整文件 |
| `+0x0C` | `0x0024D868` | 载入完整文件 |
| `+0x10` | `0x0025AE38` | 返回 `0xBB518` |
| `+0x18` | `0x0024D898` | 载入 `0xACA48` 旧格式并升级 |
| `+0x1C` | `0x0025AE20` | 检查 `u16(data+0x15C)==2` |

Mover 和 Bank 使用相同的完整文件格式。程序识别的当前格式长度为 `0xBB518`、版本为 `2`、盒数为 `100`。

### Transfer Box

| 文件偏移 | 长度 | 内容 |
|---:|---:|---|
| `0x0AAF14` | `30 × 0xE8` | 30 个传送槽主体 |
| `0x0AD5FC` | `30` | 30 个并行标签 |

| 地址 | 功能 |
|---:|---|
| `0x0019A224` | 载入一个传送槽及标签 |
| `0x0019A6F4` | 写入记录和标签并执行原程序规范化 |
| `0x0019A7E0` | 清空槽和标签 |
| `0x0019A858` | 判断槽是否含有效记录 |
| `0x0024D624` | 统计 30 个有效槽 |

传送区未发现单独的服务器记录 ID 或签名生成函数。原程序同时处理 `0xE8` 槽主体和 1 字节标签；`0x0025C978` 的处理顺序为备份候选槽、载入完整对象、在下载 Transfer Box 为空时恢复候选槽。

## 保存

`0x0024A0C4` 序列化完整 `0xBB518` 对象后执行远端更新、卡带保存和提交/回滚。

| 地址 | 原程序行为 |
|---:|---|
| `0x0024A240` | 发起远端暂存并等待异步结果 |
| `0x0024A3E4` | 卡带保存成功后发起远端提交 |
| `0x0024A420` | 卡带保存失败后发起远端回滚 |

三处分支均通过异步完成标志推进外层状态机。Mover 序列化和上传的是与 Bank 相同的完整文件格式。

# Mover v1.2 转换兼容范围

[English](version-compatibility.md) · [配置用法](../../configTemplate/templateForCopy/Bank/fakeServers/users/readme_user.zh-cn.md#enablemoverv12)

个人 `user.conf` 的 `[custom] enableMoverv1.2=false;` 默认关闭。开启只改变离线 RGBY 的已核实转换差异，
不是安装旧程序或回退全部客户端／服务器。金银／水晶、Gen5、在线模式均保留 v1.5。

## 已确认并切换的差异

| 项目 | v1.2 兼容开启 | 关闭时的 v1.5 |
| --- | --- | --- |
| 混合性别种族 | 保留原构造器按种族比例随机生成的性别 | 构造后按攻击 DV 覆盖；固定性别、无性别仍沿原构造器 |
| 闪光 | 攻击 DV=10，防御 DV 为 2/3/6/7/10/11/14/15，速度／特殊均为 10 | 防御／速度／特殊为 10，攻击为上述八值 |
| 日文／西文单字节转码 | 恢复两张旧表以及旧版语言处理；例如句点变连字符、撇号变空格，旧表不支持的部分数字／重音字符为空格 | 当前字符表及新增的语言专属处理 |

旧、新闪光条件各接受 65536 种 DV 组合中的 8 种，只有 1 种重合；不是提高闪光概率，
而是判定了不同个体。性别保留原生随机产生流程，不另建随机种子，不强制男女各半。
旧表使 Mr. Mime／Farfetch’d 等姓名变化，并可能改变是否被原比较逻辑判为昵称；
转码包装位于昵称比较前，不在保存后全局替换标点。

## 保持不变的生成项

此选项仅切换上述三项行为，其他转换和保存继续使用 v1.5 的流程。

| 项目 | 对比结果／处理 |
| --- | --- |
| 性格与经验值 | 两版调用层均按经验值除以 25 的余数取性格，并按等级重设经验值；未增加额外切换 |
| IV 保底 | 普通个体三个 31、梦幻五个 31 的构造参数一致；保留当前原构造器 |
| PID／随机值 | 仍由原构造器生成，未发现需额外切换的调用层公式；不承诺跨程序版本／随机种子逐字节复现 |
| 特性槽 | RGBY 的隐藏特性选择及无隐藏特性例外在所比较调用层一致，不改 Gen5 特性转换 |
| TID／SID | 源 TID 字节序转换、SID=0 的构造参数一致 |
| 地点／语言／主机区域 | 继续当前来源与明确配置的个人地区，不以旧版本开关绕过 user.conf |
| 梦幻处理 | 命运相遇、五项满 IV、默认名等原特殊分支保留；不恢复历史服务器接纳规则 |
| PK7、日期、校验、事务 | 保留 v1.5 对象、原校验／加密、回调与保存，不复制旧对象布局 |

开启汉化许可时，在原版姓名写入前选择汉化字符串，不在转换完成后补写对象。
英、法、意、德、西文来源使用美版汉化表，西欧单字节字符保留来源语言的 v1.5 解读；
韩版金银使用韩版表，日文来源不转码。普通 NGWord 与宝可梦筛选仍有效，
不因 v1.2 开关放行任意个体。

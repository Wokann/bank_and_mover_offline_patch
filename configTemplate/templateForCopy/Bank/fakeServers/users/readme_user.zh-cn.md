# 个人用户配置

[English](readme_user.md) · [共享服务器配置](../shared/readme_server.zh-cn.md) · [客户端及用户选择](../../client/readme_client.zh-cn.md) · [目录与保护策略](../../readme_fakeServer.zh-cn.md)

本说明供各账户共用，配置文件实际位于 `sd:/3ds/Bank/fakeServers/users/<userID>/user.conf`。
本目录的说明文件不是用户 ID，不参与账户选择；不需要为每个账户复制一份说明。
只修改所选账户的配置，不在共享 server.conf 中填写个人余额。

## 格式与字段

首次使用所选用户时自动生成。下面地区数值以日版主机为例，实际首次生成从当前主机读取。购券记录及 `balance.$币种` 都放在 `[ticket]` 下，中间只留空行，不另设余额段：

```ini
[console]
autoRegion=false;
region=0;
language=0;
country=1;
state=2;

[ticket]
purchased=false;
paid_periods=0000-00-00..0000-00-00;
trial_claimed=false;
annual_count=0;

autoCurrency=true;
currentCurrency=$JPY;
balance.$NONE=0;
balance.$JPY=0;
balance.$USD=0;
balance.$GBP=0;
balance.$EUR=0;
balance.$KRW=0;
balance.$TWD=0;
balance.$HKD=0;
balance.$AUD=0;
balance.$NZD=0;
balance.$CAD=0;
balance.$CHF=0;
balance.$ZAR=0;
```

| 条目 | 作用 |
| --- | --- |
| purchased | false 时完全忽略 paid_periods 授权，不会因日期仍有效而视为已购买；其他记录不自动清除。 |
| paid_periods | 已购期限，同样支持多时段／区域覆盖；true 时仍须匹配日期，坏数据默认不会虚构期限。 |
| trial_claimed | 是否领过试用；false 不强制触发，条件见下。 |
| annual_count | 年券购买计数，不是有效天数或首次创建标志。 |
| balance.$币种 | 该用户余额，缺损默认为 0，不与其他用户共用。 |

试用还要求：原客户端处于首次创建银行流程、试用启用且处在选定领取窗口、当前无有效券、当前无免费使用权、trial_claimed=false。过期年券或 annual_count 非零本身不排除试用；purchased 和 annual_count 不能代替原客户端首次创建状态。

年券一般增加 365 天，有效期未结束则接续，否则新起算；购买后沿原流程重查。免费活动、已购期限和试用记录可以并存，免费期优先显示免费使用权，个人购券记录保留。

## 自定义选项

以下条目放在当前账户的 `user.conf` 末尾，首次生成或缺失时默认全部关闭，不是官方设置。仅影响这个账户，不从共享 `server.conf` 读取：

```ini
[custom]
enableMoverv1.2=false;
allowFanTranslationCHN=false;
```

### enableMoverv1.2

只影响离线第一世代 RGBY 的转换：保留原构造器按种族性别比例生成的随机性别，
不再按攻击 DV 覆盖；闪光条件改为攻击 DV=10、防御 DV 为 2/3/6/7/10/11/14/15，
速度与特殊 DV 都为 10。还使用旧日文／西文字符映射：例如西文 0xE8 句点变连字符、
0xE0 撇号变空格，以及旧表不支持的数字／重音字符。无性别及固定性别仍由原构造器处理。

关闭时保留 v1.5。金银／水晶、Gen5、在线模式不进入旧版包装；不会回退服务器筛选、
银行格式、事务、地区设置或整个软件。它只复现已核实的本地转换差异，不恢复历史服务器。
版本差异见 [Poké Transporter 转换说明](https://bulbapedia.bulbagarden.net/wiki/Pok%C3%A9_Transporter#From_Generation_I_and_II)；这是社区资料，不是官方完整算法规范。

### allowFanTranslationCHN

开启后，当前账户载入的 `BanUnicodeChinese` 规则在内存中一律按关闭处理，不论共享文件中的 `enabled` 是 0 还是 1。共享 `checkPokemon.conf` 不修改，不生成其 `.bak`／`.tmp`，也不新建缺少的规则或文件。其他账户保持各自开关和共享规则的配置。若要按账户决定是否拒绝汉字，共享规则应保留 `enabled=1;`；共享规则写为 0 会对所有账户关闭该规则。

- NDS：已有姓名是 UTF-16，无需转码；恢复中文昵称／OT，即使没有昵称标记也不让默认
  种族名覆盖中文，昵称标记本身不伪造。
- VC：原始英文字母表 1 使用美版《水晶》汉化表，韩文字母表 6 使用韩版《金银》汉化表。
  指实际字符串来源，不是界面语言、主机地区或外壳地区；基于韩版编码的国际版汉化仍用韩文表。
- 只修改生成候选的姓名，原存档不改。未知／截断双字节序列整段回退原转换，不交付半截名字。
  普通韩文可能与汉化码冲突，未汉化的韩文存档应关闭此项。
- 普通 NGWord、其他筛选、原校验／加密、回调及事务保持。该选项独立于姓名词表开关；
  关闭 checkName 不会关闭汉化。与旧版选项同时开启时，最后由明确启用的汉化表恢复中文名字。
  若筛选要求修改昵称／OT，汉化保留不会恢复该字段的旧名字。要保留中文且不做姓名筛选，
  在对应来源的 checkName.conf 的 [global] 中设置 enableCheckName=false;；其他宝可梦筛选不受影响。

转换选项随后台银行下载结果交给客户端；后续策略请求读取当时的检查／姓名表。
已生成的候选不会因中途改配置追溯转码，修改选项后应返回标题重新连接。

两个汉化表均只有各自项目这一个来源，不是官方编码规范，不保证其他改版或以后改表兼容：

  固定 [charmap_cn.asm](https://github.com/TomJinW/pokecrystal_cn/blob/f487d44c0d6f75a48a4a4b975ca04bc3914b3f52/constants/charmap_cn.asm)，7615 个双字节映射。
- [TomJinW/PKMN_GSCHS](https://github.com/TomJinW/PKMN_GSCHS/tree/c3947b83c6c66a015103e1bc08bbca7f2a862d3b)：

## 主机地区与币种

`[console]` 属于所选用户。默认 `autoRegion=false`：首次生成／缺损时从应用可见的 CFG 取得四项固定数值，已有合法值不因更换主机或 Luma 改区而刷新。

| 字段 | 数值与作用 |
| --- | --- |
| autoRegion | `false` 保留下面四项手动值；`true` 在每次启动后首次确认使用该账户时，按主机启动快照更新四项并保存。同次运行中不重复覆盖。读取失败的字段保留已有有效值。 |
| region | CFG 主机大区 0–6，不是游戏版本、界面语言或经历地区；AUS=3 是保留值，见组合参考。 |
| language | CFG 系统语言 0–11，不是宝可梦语言。记录该环境值，但 v1.5 转换取用的是三个区域字段，不用它覆盖宝可梦语言或标题 L 键界面语言。 |
| country | CFG 国家／地区编号 0–255，不是两字母 ISO 文本。 |
| state | 所选 country 下的省州／地区编号 0–255，不是全球通用编号。 |

地区开关及四项在 `[console]`；币种两行放在 `[ticket]` 余额列表正上方：

| 字段 | 数值与作用 |
| --- | --- |
| autoCurrency | 默认 `true`，根据本用户最终生效的 region/country 自动选择币种并更新 currentCurrency；`false` 使用下行手动币种，允许与地区不一致。 |
| currentCurrency | `$NONE`、`$JPY`、`$USD`、`$GBP`、`$EUR`、`$KRW`、`$TWD`、`$HKD`、`$AUD`、`$NZD`、`$CAD`、`$CHF` 或 `$ZAR`。自动模式中展示所选币种；关闭自动模式后此值是实际使用的手动币种。无法映射时使用独立 $NONE 商店与余额，不兑换或合并资金。 |

标题上下切换用户只显示并保存 activeUser，不应用经过账户的自动地区／币种。标题目录刷新可以按当前默认模板修复已有配置结构、补齐新条目，但保留合法的地区和当前币种；它不创建缺失账户。点击触屏／START 确认进入对应账户后才应用自动设置；同次运行切回已使用账户不会重复按主机覆盖地区。若运行中才打开 autoRegion，下次启动生效。币种自动取本用户有效地区，不绕过固定地区单独追随主机；之后按当前配置读取，已交付客户端的结果不重算。

地区数值接受十进制或 `0x` 前缀十六进制，例如 country=1、东京 state=2，state=0x0A 等于十进制 10。不要把 Luma 裸十六进制 10 当作这里的十六进制。自动行为由 autoRegion 控制，四个数值字段不接受 auto；`none` 表示无法读取／不提供覆盖，不是自动开关。语法损坏或越界只修复对应项；合法重复项之后的非法重复项不清掉已读值。未列出的原始字节可手动保留，但不保证原版或其他工具接受。

Bank 的离线免费／试用／已购区间、礼物地区条件及货币策略使用该用户的有效地区。Mover 离线转换实际给新宝可梦赋值时使用同一用户设置，固定地区优先于 Luma。它不批量重写 Bank 中已有宝可梦的主机区域字段，不改变来源宝可梦的原生语言，也不改变原版联网、解锁或下载会话的真实地区。配置修改在后续实际读取时生效，已交付客户端的转换结果不会被事后重算。

## 备份与恢复

地区、币种、购券记录和余额作为一份 user.conf 一起发布，避免券已增加但扣款未保存的两文件分裂。
写入前的主文件保留为 user.bak，user.tmp 只作暂存。主文件缺失时先从备份读值并重建，
两者都缺失才恢复未购券／未领取／计数和余额为零的默认值。合法的手动修改保留，坏条目
逐项迁移到新版默认模板，不整份回滚覆盖合法值。地区／币种只按字段语法与范围判断：大区 0–6、系统语言 0–11、国家／省州 0–255，以及支持的币种代码；`none` 地区字段和 `$NONE` 币种仍为合法值。不以本机设置或字段组合一致性作为迁移条件。缺漏／非法条目采用默认值，未知／废弃条目不迁移。新文件先写入 user.tmp、关闭并回读验证，之后旧主文件改为 user.bak，再发布新主文件；相同内容不写盘。真实读取失败、内存不足或发布失败不按空配置覆盖原数据。没有有效来源时，默认值不能还原历史余额或购券记录。

请在停止软件后再修改或重置；删除 user.conf 后仍有 user.bak 就会从备份恢复。
完整文件清单、只读配置和特殊事务保护见[统一说明](../../readme_fakeServer.zh-cn.md#写入文件与保护策略)。

已知差异：Azahar 把百慕大 country=186 归 EUR/AUS，而 PKHeX 归 USA；香港 country=144 在 PKHeX 允许 CHN/TWN，Azahar 的判断只列 CHN；澳门 country=145 有 CFG 编号，但不在 PKHeX 允许组合内。不要仅凭模拟器允许选择就认定传输数据组合合法。AUS=3 是保留编号，PKHeX 不将其视为有效宝可梦主机区域。

台湾区系统语言 11 不代表 VC 宝可梦语言：例如 PKHeX 的 VC 语言校验对 JPN/TWN 使用日语来源，USA 使用英／法／西语来源，EUR 使用英／法／德／意／西语来源，KOR 使用韩语来源；CHN 没有对应受支持 VC 语言集合。此处说明只区分数值含义，不把系统语言改写成宝可梦语言。

### 来源与可靠性

主机大区／系统语言枚举及 CFG 接口与 [libctru 定义](https://raw.githubusercontent.com/devkitPro/libctru/master/libctru/include/3ds/services/cfgu.h)核对；四层覆盖和地址字节位置与 [Luma IPC 实现](https://raw.githubusercontent.com/LumaTeam/Luma3DS/master/k11_extension/source/ipc.c)核对。国家 ID／ISO 映射来自 [Reworked country.c](https://raw.githubusercontent.com/OasisAkari/LumaLocaleSwitcher_Reworked_zh_hans/433ec044911ef7f3a04ae8237676523a9ce7eba4/source/fbi/country.c)，省州列表来自同一版本的 [states_data.c](https://raw.githubusercontent.com/OasisAkari/LumaLocaleSwitcher_Reworked_zh_hans/433ec044911ef7f3a04ae8237676523a9ce7eba4/source/fbi/states_data.c)。

共同国家编号及全部非零省州编号与 [PKHeX 国家表](https://raw.githubusercontent.com/kwsch/PKHeX/641c26ba100225f3605e5a44b61b3b16e15a3774/PKHeX.Core/Resources/text/locale3DS/countries.txt)和其逐国家 `subregions/sr_NNN.txt` 交叉核对（[日本示例](https://raw.githubusercontent.com/kwsch/PKHeX/641c26ba100225f3605e5a44b61b3b16e15a3774/PKHeX.Core/Resources/text/locale3DS/subregions/sr_001.txt)）。两份省州表的数值差异只在部分地区的显式“0＝未设置”项，保留该项。PKHeX 未列出的 11 个国家在各自条目中注明；其 CFG 数字／ISO 代码另与 Azahar 全表核对，不代表它们存在合法宝可梦传输组合；公开改区数据不是任天堂官方支持列表，不推测缺失项。配置不强行限制玩家只能使用这些具名条目。
